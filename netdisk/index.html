账号配置中心

安全说明：这是纯静态 GitHub Pages 页面。凭据只存入此浏览器的 localStorage，不会上传到 GitHub；不要在公用设备使用。清除浏览器站点数据会删除本地配置。

目前识别到的历史爬虫字段包括 quarkCookie / quark_cookie、baidu_cookie、ucCookie / uc_cookie、uc_token、token、accessToken、refreshToken 等。不同爬虫字段并不统一，保存的表单不会自动注入 TVBox 运行进程。

导入 / 导出账号配置

导出文件仅保存在你的设备下载目录。请勿公开分享，文件可能包含可登录账号的敏感凭据。

已从整合包真实配置结构确认两种字段映射：拾光 env.json 使用 quark_cookie / baidu_cookie / uc_cookie / uc_token；星微 JAR 的两个 ext 配置使用 quarkCookie / ucCookie / token。下面两个“凭据补丁”只包含已核实字段，不会覆盖其他 ext 设置。token 的具体服务归属仍需按对应站点确认。
