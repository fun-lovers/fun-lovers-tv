# 网盘搜索与账号中心

部署入口：`/netdisk/`

## 当前功能
- 提供夸克、百度、阿里云盘、UC 的公开网页索引搜索入口。
- 提供 Cookie / Token 本地填写表单。
- 使用当前浏览器 localStorage 保存凭据；不会将凭据写入仓库或上传到 GitHub。
- 支持本地 JSON 导入、导出和清除。

## 重要兼容说明
本页是 GitHub Pages 静态前端，不具备私有后端。浏览器保存的凭据不会自动注入 TVBox、影视仓、drpy 或 JAR 进程。导出的 JSON 是账号资料备份/迁移格式，不是通用 TVBox 配置；不同爬虫使用的 ext 字段名和认证流程并不统一。

整合包审计识别到的历史字段名包括：
`quarkCookie`、`quark_cookie`、`baidu_cookie`、`ucCookie`、`uc_cookie`、`uc_token`、`token`、`accessToken`、`refreshToken` 等。审计只记录字段名，不记录任何凭据值。请按具体站点/JAR 的实现映射字段，不要将同一个 Token 猜测性地写入所有爬虫配置。

## 安全
- 仅在可信设备上输入凭据。
- 不要将导出的 JSON 上传到公开仓库、Issue、PR 或聊天群。
- 若凭据曾经公开，应立即在对应网盘平台撤销或更新。
- 本地存储不等同于密码保险箱；同一浏览器配置文件下的其他本机用户或恶意扩展可能读取页面存储。
- 页面不提供账号密码登录、会员绕过或访问控制绕过。

## 搜索范围
搜索按钮通过外部搜索引擎查询公开索引页面。结果是否存在、是否有效及是否获得授权由资源发布者和平台决定；页面不抓取第三方资源，也不保证播放。
