夸克 Cookie 配置

为 TVBox / 影视仓生成专用本地导入配置 · fun-lovers/fun-lovers-tv

1. 填写夸克 Cookie

Cookie 不会上传到 GitHub 或服务器，只保存在当前浏览器本地。生成的配置文件会包含 Cookie，请勿公开分享或提交到仓库。不要把 Cookie 发到聊天中。

2. 生成 TVBox 专用配置

本页读取公开主配置，只修改“[星微] 👶夸克┃[网盘]”站点：改用仓库内置的真实夸克网盘解析模块，并将 Cookie 写入该站点 ext。其他站点和设置保持原样。

查看公开主配置

下载文件名：tvbox-quark-cookie.local.json。文件只在本设备生成，不会上传。

3. 导入 TVBox / 影视仓

  1. 填写 Cookie，点击“生成并下载 TVBox 配置”。
  2. 打开 TVBox / 影视仓的配置管理，选择“本地文件 / 文件导入”（菜单名称因客户端版本而异）。
  3. 选择刚下载的 tvbox-quark-cookie.local.json，导入后进入“[星微] 👶夸克┃[网盘]”搜索并测试播放。
  4. 若客户端只支持 URL 导入而不支持本地文件，请勿把含 Cookie 的配置上传到公开 Pages；使用客户端支持的本地 ext / 本地配置方式。

该文件包含个人 Cookie。不要上传到公开仓库、Issue、PR 或分享给他人。点击“清除本设备”只清除浏览器副本，不会撤销夸克账号登录会话。
